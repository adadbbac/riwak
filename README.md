# رواق العربية — المحور الأول: الشعر الجاهلي

هذه نسخة جاهزة للنشر كموقع ثابت (Static Site).

## البنية
- `index.html` الصفحة الرئيسية
- `axis-01.html` صفحة المحور الأول
- `lesson-01.html` ... `lesson-09.html` الدروس التسعة
- `404.html` صفحة الخطأ

## الخصائص
- جميع الصفحات مستقلة ولا تعتمد على صور أو خطوط خارجية.
- الخط أميري مضمّن داخل الصفحات.
- الصور مضغوطة WebP ومضمّنة داخل HTML.
- تصميم متجاوب مع الهاتف والاتصال البطيء.
- الأنشطة موحّدة بصريًا مع حالات اختيار وتغذية راجعة.
- لا توجد صورة للأستاذ؛ يظهر الاسم فقط: **الأستاذ صالح الدريدي**.

## النشر عبر GitHub + Cloudflare Pages
1. أنشئ مستودعًا جديدًا في GitHub وارفع محتويات هذا المجلد إلى الجذر.
2. في Cloudflare Pages اختر إنشاء مشروع من Git ثم اربط مستودع GitHub.
3. اجعل نوع المشروع Static، ولا تضف Build command.
4. اجعل مجلد الإخراج هو الجذر `/`.
5. بعد النشر اختبر: الصفحة الرئيسية، صفحة المحور، الدروس التسعة، الأزرار التفاعلية، وعرض الهاتف.
6. عند كل تحديث: ارفع التغييرات إلى GitHub، وستعيد Cloudflare النشر تلقائيًا.

> قبل النشر النهائي يُستحسن فتح الصفحات محليًا على الهاتف والحاسوب واختبار جميع الروابط والأنشطة.
